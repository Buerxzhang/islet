islet：Mac 菜单栏里的灵动岛

免费开源的 macOS 菜单栏工具。CPU、内存、网速这些常看的数字，正在播放的音乐和频谱，蓝牙耳机、键盘、鼠标的电量，都收进菜单栏里的一枚胶囊。

islet 是什么

islet 把系统指标、音乐和蓝牙电量合进菜单栏里的一枚胶囊：平时是一排指标，有声音时展开出封面和频谱，点开任意一项是详细面板。刘海屏和外接显示器都能用。

另外还有两个小工具：让外接鼠标像触控板一样顺滑地滚动，以及为 2K、带鱼屏开启 HiDPI。

功能

Mac 菜单栏怎么显示 CPU、内存、网速和温度CPU、GPU、内存、网速、温度、功耗、风扇，一排看全，点开有走势和应用排行。 Mac 上有类似 iPhone 灵动岛的软件吗刘海屏和普通屏都能用：平时是一排指标，有声音时展开封面和频谱。 Mac 菜单栏显示正在播放的音乐和实时频谱支持常见的音乐播放器，频谱跟着封面变色。 Mac 菜单栏怎么直接看到蓝牙耳机、键盘、鼠标的电量每台设备一个电量圆环，低电量自动提醒，点一下就能连接或断开。 Mac 外接鼠标滚轮一卡一卡的，怎么像触控板一样顺滑让有刻度的鼠标滚轮滚得像触控板一样顺滑，触控板不受影响。 Mac 外接 2K 显示器字体发虚，怎么开启 HiDPI一键为 2K、带鱼屏添加 HiDPI 档位，文字更细腻，切换分辨率也更直观。
常见问题

常见问题

islet 免费吗？

免费，开源，使用 MIT 许可证，源代码在 GitHub 上公开。

支持哪些 Mac？

支持 Apple 芯片和 Intel，需要 macOS 14 或更新版本；实时频谱需要 macOS 14.2 或更新版本。刘海屏 MacBook 和外接显示器都能用。

第一次打开提示「无法验证开发者」怎么办？

在「应用程序」里右键 islet，选「打开」；或者到「系统设置 → 隐私与安全性」点「仍要打开」。

会收集我的数据吗？

不收集、不上传任何使用数据。只在查询公网 IP、测量延迟、检查和下载更新、查询 GitHub 标星数时联网；画频谱只读取电脑播放的声音，不录麦克风。

支持哪些音乐软件？

软件自己声明为「音乐」类别的会自动识别，另外内置了网易云音乐、QQ 音乐、Apple Music、Spotify、酷狗、酷我等名单。目前只专门适配过网易云音乐和 QQ 音乐，其他播放器有问题欢迎到 GitHub 提交 issue。

新装后默认是什么样子？

有刘海的屏悬浮在刘海下方，否则在菜单栏最左侧；分体胶囊、渐变样式；显示 CPU、内存、温度、网速（无刘海的屏再加 GPU、磁盘、功耗、风扇）、音乐和蓝牙电量。平滑滚动、HiDPI、风扇调速默认关闭。

怎么更新？

有新版本时会弹窗提示：点更新下载，下载好后由你决定何时重启，设置会保留。也可以在设置的「关于」页手动检查。
